## Evidence

Measurements, benchmarks, command output, doc citations. An assertion without
evidence does not belong here. If the decision is a judgment call with no
supporting data, say that explicitly rather than dressing it up.

## Consequences

What becomes easier. What becomes harder. What this locks in. What it costs.

## Reversal path

If there is no practical reversal path, say so — that is itself a reason to
think harder before accepting.
